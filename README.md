## How to Run

Open the `python_assignment` folder in Visual Studio Code, open the required Python file, and run it using the VS Code terminal.

Example:

```bash
python unit_1/student_info.py
```

Another example:

```bash
python unit_2/prime_check.py
```

No external libraries are required except Python's standard `math` and `random` modules.
